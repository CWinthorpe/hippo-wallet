# Hippo Wallet brand and font notices

Hippo Wallet is a private fork of Rabby Wallet. The upstream source remains available under the MIT License in [`LICENSE`](../LICENSE); its copyright notice and permission terms are preserved unchanged.

## Hippo Wallet artwork

The Hippo Wallet mark and wordmark in this repository are original assets produced for this fork. The mark uses an independently drawn front-facing pixel hippo silhouette. It does not reuse the upstream Rabby rabbit artwork or the Resupply protocol's side-profile hippo silhouette.

Core palette:

- Midnight: `#111629`
- Surface: `#262C40`
- Electric blue: `#0372FF`
- Mint: `#26E99A`
- White: `#FFFFFF`

The reproducible source is [`scripts/generate-hippo-brand-assets.py`](../scripts/generate-hippo-brand-assets.py). The indexed 16×16 Aseprite master is [`brand/hippo-wallet-icon.aseprite`](../brand/hippo-wallet-icon.aseprite).
