# Importing an existing MetaMask account

Hippo Wallet can import a seed phrase or an individual account's private key. Export secrets only from the installed MetaMask extension itself—never from a website, chat message, or unsolicited prompt.

## Seed phrase

Follow MetaMask's official recovery-phrase guidance, then choose **Import Seed Phrase** in Hippo Wallet.

<https://support.metamask.io/configure/wallet/how-to-reveal-your-secret-recovery-phrase/>

## Individual private key

Follow MetaMask's official account-export guidance, then choose **Import Private Key** in Hippo Wallet.

<https://support.metamask.io/configure/accounts/how-to-export-an-accounts-private-key/>

## Safety

- Confirm that the page showing the secret is the installed MetaMask extension.
- Disconnect screen sharing and close recording software before revealing a secret.
- Never upload, email, photograph, or paste the secret into a web page.
- Clear the clipboard after import.
- Hippo Wallet encrypts imported secrets locally with your wallet password.
