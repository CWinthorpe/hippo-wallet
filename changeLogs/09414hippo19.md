Security fixes (verified applied, focused suites green):
- #4216 (527ddb7c4) — dapp RPC method dispatch no longer traverses the
  prototype chain. New `background/utils/getOwnMethod.ts` own-property lookup
  gates `internalMethod`, `providerController` mapping (rpcFlow + buildin
  provider), and the background port's subscription-manager dispatch; an
  unmapped method in the built-in provider now throws instead of falling
  through. Ported intact with all four upstream regressor suites
  (getOwnMethod / buildinProviderPrototype / providerPrototypeDispatch /
  rpcFlowApprovalGuards).
- #4211 (88da2c8c1) — EIP-712 render/sign-mismatch class closed. Type-graph
  size limits (`isTypeGraphTooLarge`), strict value checks for bool/string/
  address coercion (`findInvalidTypedDataValue`), generic `invalid typed
  data` error text (no attacker-controlled strings in errors). The upstream
  `Sentry.captureMessage` leg is inert in Hippo builds (no DSN, no
  `Sentry.init`, no ingestion — enforced by the privacy suite); validation
  itself never depends on reporting and stays fail-closed.
- #4208 (34b310850) — Extra Fee Protection (on by default, password-gated
  disable): blocks non-zero builder/integrator fee approvals for
  Hyperliquid/Aster/Lighter on their official origins only; fails closed on
  matched-rule parse failures. Ported intact (background utils, preference
  field, Settings toggle, SignTx/SignTypedData/SignText gating, footer
  disabled-state, all six upstream test suites).
