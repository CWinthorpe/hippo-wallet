# v0.94.7-hippo.13 — Rabby v0.94.7 sync

This release integrates the RabbyHub/Rabby v0.94.7 stable line (21 commits) with Hippo's
privacy and product-policy customizations preserved.

- Security toolchain: the Warden (SecSDK) build-time hardening plugin is re-enabled in
  production and debug webpack builds, matching upstream's decision to restore it in
  v0.94.7; `warden-for-js` is updated to 3.0.2 and the module policy is regenerated from
  this repository's own bundle graph at build time.
- Ledger: signing diagnostics now survive malformed optional fields, classify device
  lock/disconnect/busy states, and record whether the blind-sign fallback step was used
  (diagnostics only — no signing decision changes).
- Send flow: pasted recipient addresses tolerate surrounding whitespace only when the
  trimmed text is a strictly valid address, and stale ENS lookups can no longer replace
  the recipient you selected.
- Internal: UI business stores complete the rematch-to-zustand migration and gas/token
  caches move to a per-window query client; Hippo keeps its consent gate — no business
  store initializes before the remote-data policy is configured.
- Unchanged: CoW Swap remains the only swap surface; removed Rabby products
  (perps, bridges, Rabby Swap, gas account, points, staking, lending, NFT trading)
  remain removed; no Sentry transport, no installation identifier, no Rabby identity.
