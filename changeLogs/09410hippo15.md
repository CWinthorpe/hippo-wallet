# v0.94.10-hippo.15 — Rabby v0.94.10 security line

Ports the RabbyHub/Rabby v0.94.10 stable release with Hippo's privacy and
product-surface invariants preserved.

Security-relevant fixes:
- #4126 repairs the DappActions risky-method blacklist: the entry
  `setApproveToAll` never matched any real ABI (typo), so `setApprovalForAll`
  actions were displayed as safe; the corrected list covers
  `setApprovalForAll`, `transferFrom`, and `safeTransferFrom`, matches on the
  ABI-normalized function name, and re-checks before action calldata is
  returned.
- #4118 hardens the typed-data approval screen: internal-origin requests
  arriving without an explicit `$ctx` no longer throw (crash-fix falling back
  to the existing chain resolution); upstream regression tests now cover
  missing context and the required-data readiness gate that keeps the security
  engine blocked until action data lands.
- #4128 fail-closed reset of the DappActions validity flag when chain or
  action data is missing.
- #4125 corrects Morph L1 data-fee estimation (per-chain Scroll-style oracle
  predeploy map), closing a balance-check under-reserve on Morph; a failed
  oracle estimate still propagates and is never treated as zero.
- #4123 spender display-list refresh (additions plus revocations).
- #4130 publishes Rabby's SlowMist audit report for the already-integrated
  91404b18a fixed version. Finding N3 (WebCrypto hooking in sync-wallet) was
  fixed upstream in that line. Finding N1 (EIP-712 `domain.chainId=0` skips
  chain-consistency validation because of a truthiness check) remains OPEN
  upstream. Hippo ports upstream signing-path fixes intact and does not author
  a divergent fix (approval lifecycle is upstream-owned); the closure will
  port with the upstream release that ships it.

Also from the stable line: #4127 bootstrap diagnostics and #4124
IndexedDB-open failure reporting (ported to Hippo's inert, disabled Sentry
shim — no telemetry endpoint exists; the background service worker keeps
console-only reporting since it ships no Sentry SDK), #4122 CI debug-job
removal.

Not ported (Hippo policy): #4117 `@rabby-wallet/rabby-swap` bump (RabbySwap
is a removed product; Hippo has no dependency on the package), the matching
`SecSDK` swap-module entries, and upstream's Sentry fallback-DSN test
scaffolding (Hippo's no-DSN privacy contract test is kept instead).

Customizations preserved: Hippo identity/branding, no Sentry init/DSN or
telemetry endpoint, CoW-only swaps via the order book, RPC policy (custom
wins; 1RPC → dRPC → PublicNode → 0xRPC; no relay), removed surfaces (Gas
Account sponsored submission, points/badges, perps, bridges, staking, faucets,
NFT trading, RabbySwap), consent-gated remote data. Approval lifecycle is
upstream-owned.
