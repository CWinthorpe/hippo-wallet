# v0.94.4-hippo.12 — security backport

This security-only release backports RabbyHub/Rabby PR #4055 ("sec: disable sec sdk",
Rabby v0.94.6): Hippo disables the Warden-for-JS build-time hardening SDK in production
and debug builds, matching Rabby's upstream decision.

- The SecSDK/warden-for-js WardenPlugin is no longer instantiated in the webpack build.
  It is compiled out of every bundle. No runtime code is affected.
- No other upstream change is included. Hippo behavior, branding, privacy controls and
  CoW Swap surface are unchanged.
