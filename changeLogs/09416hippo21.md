Security fixes (verified applied, focused suites green):
- #4262 (4bc916a21) — dapp transaction approval binding. `eth_sendTransaction`
  now refuses to sign unless the resolved approval's `from` and `chainId`
  match the request's `txParams` exactly (case-insensitive address, numeric
  chain id), closing the approval→sign substitution window where a queued
  approval could be resolved for one account/chain and signed for another.
  Dapp-supplied `isSpeedUp`/`isCancel` flags are stripped for external
  origins so a dapp cannot impersonate the wallet's own speed-up/cancel
  flows. Regressor: dappTransactionBinding.test.ts (adapted: the mock of
  Hippo-removed `gasAccountLogin` dropped; product controller never
  imports it).
- #4266 (c1b8cc8d2) — offscreen message sender authentication. Every
  hardware bridge receiver (trezor, ledger, bitbox02, onekey, lattice,
  imkey offscreen scripts plus the background-side listeners in
  eth-ledger-keyring, bitbox02- and trezor-offscreen-bridge) now requires
  `isPrivilegedOffscreenSender` (same extension id, no `tab` on the sender),
  per the PR's stated threat: a same-browser extension with debugger
  permission driving the hardware wallet directly. Hippo keeps this AND-ed
  with its existing stricter `isTrustedBackgroundSender` exact-`sw.js`-URL
  guard on offscreen receivers, so no same-extension page can reach a
  device action. Regressor: offscreenMessageSecurity.test.ts (the upstream
  background-sender fixture passes both guards).
- #4279 (805f7d95a) — typed-data validation is no longer report-only:
  signTypedData rejects (invalidParams) when EIP-712 field value types
  mismatch their declared types, instead of only reporting and proceeding to
  the approval screen. Regressor: typedDataValidation.test.ts (adapted:
  gasAccountLogin mock removed, behavior unchanged).
- #4258 (949833222) — background startup race: UI port requests and the
  openapi/controller dispatch are held behind a readyGate until
  `restoreAppState` finished loading service stores; restore failure rejects
  held and later requests with `disconnected` instead of leaving them
  pending against undefined stores. Fixes the RABBY-5W7/5W8/5W9
  pre-restore-read crash class. Regressor: readyGate.test.ts.
- #4259 (210ad2463) — Trezor signing failures are classified by Connect
  code (user-cancel vs device error) with the code bound to the error it
  came with; the Sentry grouping hunks resolve to Hippo's inert telemetry
  state (no init, no ingestion, console-only bootstrap diagnostics).
  Regressor: trezorSigningDiagnostics.test.ts.
- #4263 (9c69862f9) — Safe keyring keeps local signature records in sync
  with the Safe service so failed-create retries stop 404ing
  (gnosisKeyringRetry.test.ts).
- #4272 (883c8e9e1) — gas prices beyond `Number.MAX_SAFE_INTEGER` convert
  to hex without throwing (hexQuantity.ts; affects tx gas typing paths).
  Regressors: hexQuantity/transaction/customNetworkGas tests.
- #4269 (aae889096) — dev-server code-inspector restricted to extension
  requests (dev-only surface; yarn patch files added).
  Regressor: codeInspector.test.ts.
