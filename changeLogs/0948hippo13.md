# v0.94.8-hippo.13 — Rabby v0.94.8 security line

Ports the RabbyHub/Rabby v0.94.8 stable release with Hippo's privacy and
product-surface invariants preserved.

Security fixes:
- #4083 block signing when an unprocessed security rule triggers (multi-action
  approvals re-checked before resolve; upstream approval-identity binding).
- #4087 explorer scan links restricted to http(s); `rel=noopener` on outbound
  transaction links (blocks javascript:/data: URL execution from chain
  metadata).
- #4088 broadcast chain pinned to the chain captured at approval time; a dApp
  switching chains mid-approval can no longer redirect a signed transaction.
- #4093 custom-network receipt status preserved (reverted transactions no
  longer render as success).
- #4076/#4097 upstream re-enabled the SecSDK build-time hardening plugin
  (reversing #4055) and bumped warden-for-js to 3.0.2; Hippo follows upstream.
- #4072 send-address input hardening (stale ENS result guard, paste
  normalization).

Customizations preserved: Hippo identity/branding, no Sentry/telemetry,
CoW-only swaps via the order book, RPC policy (custom wins; 1RPC → dRPC →
PublicNode → 0xRPC; no relay), removed surfaces (Gas Account sponsored
submission, points/badges, perps, bridges, staking, faucets, NFT trading,
RabbySwap), consent-gated remote data. The bespoke consent-hardening layer
of 2026-09 is not present; approval lifecycle is upstream-owned.
